从压缩到伸长的弹簧

如图所示，两个质量均为 1 kg 的相同物块 A、B 用一个劲度系数为 500 N/m 的轻弹簧连接，两物块都处于静止状态。现用竖直力 F 缓慢地向上拉物块 A，直到物块 B 刚好离开水平地面为止。取 g = 10 m/s²，这个过程中物块 A 移动的距离是（　）。

  1. A1 cm
  2. B2 cm
  3. C4 cm
  4. D8 cm
Show answer 查看分步解析Hide answer 收起解析＋
参考答案C，4 cm

一步一步推导

  1. 初态对 A 受力分析：重力 mg 向下，弹簧支持力向上。由平衡得 kx₁ = mg，故弹簧最初被压缩 x₁ = 10/500 m = 2 cm。
  2. B 刚要离地时，地面对 B 的支持力变为零。弹簧必须向上拉 B，因此弹簧已伸长，且 kx₂ = mg，得 x₂ = 2 cm。
  3. 在此之前 B 的位置不变。A 的上移距离等于弹簧从压缩 2 cm 到伸长 2 cm 的总长度变化：Δh = x₁ + x₂ = 4 cm。
Δh = mg/k + mg/k = 2mg/k = 0.04 m
易错提醒

初态是压缩，末态是伸长，两段形变量要相加。

练习 02原 PDF 第 2 页

弹力大小与弹力方向

如图所示为一轻质弹簧的弹力和长度的关系图像（轻质弹簧未超过弹性限度），下列说法正确的是（　）。

  1. A弹簧的原长为 6 cm
  2. B弹簧的劲度系数为 10 N/m
  3. C弹簧在长度分别为 4 cm 和 8 cm 时受到的弹力相同
  4. D在该弹簧两端各加 0.5 N 的拉力，静止时弹簧的长度为 6.5 cm
Show answer 查看分步解析Hide answer 收起解析＋
参考答案A、D

一步一步推导

  1. 图像在 ℓ = 6 cm 时弹力为零，因此弹簧原长 ℓ₀ = 6 cm，A 正确。
  2. 取图上 (8 cm, 2 N)：形变量为 0.02 m，k = 2/0.02 = 100 N/m，B 错误。
  3. 4 cm 和 8 cm 分别对应压缩和伸长 2 cm。弹力大小都为 2 N，但对同一端而言弹力方向相反，不能说弹力相同，C 错误。
  4. 两端各加 0.5 N 的拉力，弹簧中的拉力是 0.5 N。伸长量 x = 0.5/100 m = 0.5 cm，长度应为 6.5 cm，D 正确。
F = k|ℓ − ℓ₀|；k = 100 N/m；ℓ = 6 cm + 0.5 cm = 6.5 cm
易错提醒

弹力是矢量：大小相同不等于弹力相同。两端拉力不相加。

练习 03原 PDF 第 2 页

木板抽动时的滑动摩擦

如图所示，足够长的长木板 B 放在水平地面上，木块 A 放在 B 上，右侧通过一段轻绳与水平弹簧测力计的挂钩连接。现用大小为 F 的水平拉力作用在 B 上使其在水平面上向左运动。稳定时，水平弹簧测力计的示数为 Fₜ，下列说法正确的是（　）。

  1. A木块 A 受到的摩擦力为静摩擦力
  2. B无论木板 B 的速度为多大，A、B 间的摩擦力都等于 Fₜ
  3. C长木板 B 向左加速运动时，A、B 间的摩擦力变大
  4. D长木板 B 向左减速运动时，A、B 间的摩擦力减小
Show answer 查看分步解析Hide answer 收起解析＋
参考答案B

一步一步推导

  1. 木块 A 被绳固定，木板 B 向左运动，A、B 接触面有相对滑动，所以 A 受到的是向左的滑动摩擦力。
  2. A 在水平方向平衡，向右的绳拉力等于向左的滑动摩擦力，因此 f = Fₜ。
  3. 按高中滑动摩擦模型，f = μN = μm_Ag。材料和压力不变，摩擦力与木板的速度及加速度无关，因此 B 正确，C、D 错误。
f = μN = μm_Ag = Fₜ
易错提醒

B 选项适用于木板仍相对 A 滑动的过程；木板停止后应重新判断摩擦状态。

练习 04原 PDF 第 3 页

先判断静摩擦还是滑动摩擦

如图所示，一质量不计的弹簧原长为 10 cm，一端固定于质量 m = 2 kg 的物体上，另一端施一水平拉力 F。已知物体与水平面间的动摩擦因数为 0.2，设最大静摩擦力与滑动摩擦力相等，取 g = 10 m/s²。

（1）当弹簧拉长至 12 cm 时，物体恰好匀速运动，弹簧的劲度系数为多大？

（2）若将弹簧拉长至 11 cm，物体受到的摩擦力大小为多少？

（3）若将弹簧拉长至 13 cm，物体受到的摩擦力大小为多少？

    Show answer 查看分步解析Hide answer 收起解析＋
    参考答案（1）200 N/m；（2）2 N（从静止加载）；（3）4 N

    一步一步推导

    1. 竖直方向 N = mg = 20 N。滑动摩擦力和最大静摩擦力均为 μN = 0.2 × 20 = 4 N。
    2. （1）匀速时弹簧拉力等于 4 N。弹簧伸长量为 12 − 10 = 2 cm = 0.02 m，所以 k = 4/0.02 = 200 N/m。
    3. （2）按各小问分别从静止状态加载的通常理解，长度为 11 cm 时拉力为 k × 0.01 = 2 N，小于最大静摩擦力，物体保持静止，静摩擦力为 2 N。
    4. （3）长度为 13 cm 时拉力为 k × 0.03 = 6 N，超过最大静摩擦力，物体滑动，摩擦力为 4 N。
    f_max = μmg = 4 N；k = 200 N/m；F_11 = 2 N；F_13 = 6 N
    易错提醒

    第（2）问有状态前提：若物体原来仍在滑动，摩擦力为 4 N，不能仅凭弹簧长度断定为 2 N。

    磁吸块与通知纸的受力

    如图，某办公室有一竖直铁质的公告栏，通知纸用磁吸块压在公告栏上面，下列说法正确的是（　）。

    1. A通知纸受到 4 个力作用
    2. B磁吸块受到的摩擦力方向竖直向下
    3. C通知纸受到公告栏的摩擦力大小大于其自身重力大小
    4. D磁吸块对通知纸的压力和公告栏对通知纸的压力是一对相互作用力
    Show answer 查看分步解析Hide answer 收起解析＋
    参考答案C

    一步一步推导

    1. 先分析磁吸块：重力向下，纸对磁吸块的静摩擦力向上，与其重力平衡。所以 B 错误。
    2. 由牛顿第三定律，磁吸块对纸的摩擦力向下，大小等于磁吸块的重力。
    3. 纸在竖直方向受到自身重力、磁吸块向下的摩擦力、公告栏向上的摩擦力。因此公告栏的摩擦力 f = G_纸 + G_磁吸块 > G_纸，C 正确。
    4. 纸还受到两侧的两个压力，共受 5 个力，A 错误。D 中两个压力都作用在纸上，不是一对相互作用力，D 错误。
    f_栏→纸 = G_纸 + G_磁吸块
    易错提醒

    相互作用力必须作用在两个不同物体上。纸并不因磁吸块而直接受到磁力。

    弓弦张力的合成

    射箭比赛所用的弓如图所示，已知弓的顶部跨度为 ℓ，且拉弓过程中顶部跨度保持不变；弦光滑均匀且弹性良好，其自由长度为 ℓ，劲度系数为 k。发射箭时箭连同附加装置处于弦正中间，弦的长度为 2ℓ，设弦的弹力满足胡克定律，则发射瞬间弦的弹力大小为________，此时弦对箭的作用力大小为________。

      Show answer 查看分步解析Hide answer 收起解析＋
      参考答案kℓ；√3 kℓ

      一步一步推导

      1. 整根弦由原长 ℓ 伸长到 2ℓ，伸长量为 ℓ。胡克定律给出弦内张力 T = kℓ。
      2. 箭处于弦的中点，故两段弦各长 ℓ。两固定端之间的距离也为 ℓ，三条边组成等边三角形，两段弦在箭处的夹角为 60°。

      练习 02原 PDF 第 2 页

      已知合力与一个分力的方向

      已知两个共点力的合力为 60 N，分力 F₁ 的方向与合力 F 的方向成 30° 角，F₂ 的大小为 40 N，则（　）。

      1. AF₁ 的大小是唯一的
      2. BF₂ 的方向是唯一的
      3. CF₂ 有两个可能的方向
      4. DF₂ 可取任意方向
      Show answer 查看分步解析Hide answer 收起解析＋
      参考答案C

      一步一步推导

      1. 以合力 F 为基准，将 F 分解到 F₁ 的方向及其垂直方向。垂直于 F₁ 的分量必须完全由 F₂ 提供，其大小为 60 sin30° = 30 N。
      2. F₂ 的大小为 40 N，因此它沿 F₁ 方向的分量可取 ±√(40² − 30²) = ±10√7 N。
      3. 相应地，F₁ = 60 cos30° ∓ 10√7 = 30√3 ∓ 10√7 N。两值约为 25.5 N 和 78.4 N，均为正，因此都满足给定方向。
      4. 两个有效的 F₁ 分别对应两个不同方向的 F₂，故只有 C 正确。
      F₁ = 30√3 ± 10√7 N；F sin30° = 30 N < F₂ = 40 N < F = 60 N
      易错提醒

      先检查几何解是否对应正的力大小，不能见到圆与直线就直接说有两个解。

      旋转一个力后的合力范围

      如图所示，物体在五个共点力的作用下保持平衡，其中 F₁ 大小为 10 N。如果绕作用点旋转力 F₁，而保持其余四个力大小、方向都不变，那么这五个力的合力的大小可能为（　）。

      1. A30 N
      2. B21 N
      3. C14 N
      4. D7 N
      Show answer 查看分步解析Hide answer 收起解析＋
      参考答案C、D

      一步一步推导

      1. 初态五力平衡，所以其余四个力的合力 R = −F₁，大小为 10 N，方向与原来的 F₁ 相反。
      2. 旋转后 F₁′ 大小仍为 10 N，新的总合力为 R + F₁′。问题转化为两个大小均为 10 N 的力的合成。
      3. 两力合力大小在 |10 − 10| 与 10 + 10 之间，即 0 至 20 N。14 N 和 7 N 可以出现，30 N 和 21 N 不可能。
      F_合 = |F₁′ − F₁|；0 ≤ F_合 ≤ 20 N
      易错提醒

      其余四力的合力并不为零，而是抵消原来的 F₁。

      练习 04原 PDF 第 2 页

      斜面与挡板的支持力

      重为 G 的球，置于倾角为 α 的光滑斜面上，下方用垂直斜面的光滑挡板挡住使球静止，受力分析如图所示。

      （1）求斜面对球的支持力 F_N1 和挡板对球的支持力 F_N2。

      （2）若挡板竖直放置，斜面对球的支持力和挡板对球的支持力分别为多少？

        Show answer 查看分步解析Hide answer 收起解析＋
        参考答案（1）G cosα、G sinα；（2）G/cosα、G tanα

        一步一步推导

        1. （1）所有接触面光滑，支持力都垂直接触面。挡板垂直斜面时，挡板支持力沿斜面向上，斜面支持力垂直斜面向上。
        2. 将重力分解到沿斜面和垂直斜面的方向：沿斜面分量为 G sinα，垂直斜面分量为 G cosα。平衡得到 F_N2 = G sinα、F_N1 = G cosα。
        3. （2）挡板改为竖直后，挡板支持力改为水平向右；斜面支持力仍垂直斜面。
        4. 竖直方向只有斜面支持力的分量平衡重力：F_N1 cosα = G，故 F_N1 = G/cosα。水平方向 F_N2 = F_N1 sinα = G tanα。
        挡板⊥斜面：F_N1 = G cosα，F_N2 = G sinα
挡板竖直：F_N1 = G/cosα，F_N2 = G tanα
        易错提醒

        挡板方向改变，支持力方向也改变，必须重新列平衡方程。

        两根绳谁先断

        如图所示，轻质细绳 AO 和 BO 相交于 O 点，其 A、B 端是固定的，在 O 点用轻质细绳悬挂质量为 m 的物体。平衡时 AO 水平，BO 与水平方向的夹角为 θ。已知细绳 AO 和 BO 能承受的最大拉力相同，AO 和 BO 的拉力大小分别为 F₁ 和 F₂，重力加速度为 g，则（　）。

        1. AF₁ = mg tanθ
        2. BF₂ = mg/sinθ
        3. CF₁ 与 F₂ 的合力大小为 mg，方向竖直向下
        4. D增大物体的质量，最先断的是细绳 BO
        Show answer 查看分步解析Hide answer 收起解析＋
        参考答案B、D

        一步一步推导

        1. 对结点 O 受力分析：AO 绳向左拉，BO 绳斜向右上拉，下方绳竖直向下拉且拉力为 mg。
        2. 竖直方向平衡：F₂ sinθ = mg，所以 F₂ = mg/sinθ，B 正确。
        3. 水平方向平衡：F₁ = F₂ cosθ = mg cotθ，A 错误。F₁、F₂ 的合力竖直向上且大小为 mg，C 的方向错误。
        4. 由于 0 < cosθ < 1，F₁ = F₂ cosθ < F₂。在最大承受拉力相同的前提下，增大 m 时 BO 先达到极限，D 正确。
        F₂ = mg/sinθ；F₁ = mg cotθ；F₂ > F₁
        易错提醒

        两根上方绳的合力向上，用来平衡下方物体的重力。

        光滑晾衣绳上的衣服

        如图所示，光滑、轻质、不可伸长的晾衣绳两端分别固定于竖直杆上的 a、b 两点，一质量为 m 的衣服静止悬挂于绳上某点；若在绳上另一点继续悬挂另一质量为 M 的衣服，已知 m < M，两衣架质量均可忽略不计，则最终两衣服在绳上的状态为（　）。选项的几何位置见下图。

        1. A图 A：两衣服分处绳上不同位置
        2. B图 B：两衣服分处绳上不同位置
        3. C图 C：两衣服合在一起，位于偏右处
        4. D图 D：两衣服合在一起，位于偏左处
        Show answer 查看分步解析Hide answer 收起解析＋
        参考答案D

        一步一步推导

        1. 衣架与绳之间光滑，衣架可沿绳滑动。绳轻且无摩擦，静止时各段张力大小相等。
        2. 先看一件衣服：衣架两侧等大的张力合力必须竖直向上，故两侧绳与竖直方向的夹角相等。
        3. 若两件衣服分开，设三段绳依次为左、中、右段。对左衣架，水平平衡要求左、中段的水平张力大小相等；对右衣架同理。等张力使三段绳的倾角绝对值相等。左衣架要有向上的合力，中段需向右上倾斜；此时右衣架两侧绳的竖直分量相消，无法托住右衣服。因此分开不能平衡。
        4. 两衣服最终滑到同一处，两外侧绳的倾角应相同。右端 b 高于左端 a，故右侧绳段更长，汇合点应靠左。在给定选项中对应 D。
        T_左 = T_右；两侧绳的倾角相同；T_左 + T_右 的矢量和 = (m + M)g 向上
        易错提醒

        “光滑”意味着衣架可滑动，不能把衣服的位置当作固定结点。

        练习 02原 PDF 第 2 页

        缓慢爬上半球形屋顶

        我国 2007 年建成的国家大剧院外部呈椭球型。为了简化，将国家大剧院的屋顶近似为半球形。某警卫人员在执行特殊任务时，必须在屋顶上向上缓慢爬行，他在爬行的过程中屋顶对他的（　）。

        1. A支持力不变
        2. B支持力变小
        3. C摩擦力变小
        4. D摩擦力变大
        Show answer 查看分步解析Hide answer 收起解析＋
        参考答案C

        一步一步推导

        1. 缓慢爬行可按准静态平衡处理。设人所在位置的局部切面与水平面夹角为 α。
        2. 将重力分解到切向和法向，得到支持力 N = mg cosα，静摩擦力 f = mg sinα，摩擦力沿屋顶切面向上。
        3. 沿半球屋顶向上靠近顶点时，局部坡度变缓，α 减小。所以 cosα 增大、sinα 减小，即支持力增大、摩擦力减小，选 C。
        N = mg cosα ↑；f = mg sinα ↓（向上爬，α ↓）
        易错提醒

        这里采用“缓慢”对应的准静态模型；不要凭爬行方向判断摩擦力大小。

        转动木板时的动态平衡

        如图，一小球静止在竖直墙壁和木板之间。现将木板从图示位置沿顺时针方向缓慢旋转至水平位置，不计一切摩擦，则下列说法正确的是（　）。

        4. D小球对墙壁的压力变大，对木板的压力变大

        牛顿定律与参考系

        1687 年，英国物理学家艾萨克·牛顿在伽利略、惠更斯等人关于动力学的一些观点的基础上，总结整理出三条描述力和运动关系的基本定律——牛顿运动定律，发表在《自然哲学的数学原理》一书中，为后来物理学很多领域的发展奠定了坚实可靠的基础。在宏观、低速、弱引力情况下，牛顿运动定律对物体的运动都能给出很好的解释或预测。关于牛顿运动定律，下列说法正确的是（　）。

        2. B若作用在运动物体上的力消失，则因为惯性，物体的加速度要隔一段时间才会消失
        3. C火车内静坐的乘客看到车内桌上的苹果在没有任何人碰的情况下突然朝自己滚来，在他看来，苹果的突然运动不能用牛顿第二定律解释
        4. D根据牛顿第三定律，一本静止于水平桌面上的书受到的重力和支持力一定大小相等、方向相反、作用在同一直线上
        Show answer 查看分步解析Hide answer 收起解析＋
        参考答案C（以车厢为参考系，直接使用 F_合 = ma 时）

            四物块与压力传感器

            水平地面上并排放置四个质量均为 m 的相同物块，每个物块与地面间的动摩擦因数均为 μ，且最大静摩擦力等于滑动摩擦力。物块 1、2 之间固定一个质量不计的压力传感器。t = 0 时，对物块 1 施加一水平力 F，下列说法正确的是（　）。

            1. A若四个物块均静止，则物块之间的弹力的比例从左往右依次为 3∶2∶1
            2. B若四个物块一起向右匀加速运动，则物块之间的弹力的比例从左往右依次为 3∶2∶1
            3. C若 F 随时间均匀变化，满足关系 F = kt，则在 t = μmg/k 时，压力传感器的示数 F₁ = μmg
            4. D若 F 随时间均匀变化，满足关系 F = kt，则在 t = 6μmg/k 时，四个物块的加速度为 0.5μg

            参考答案B、D

            一步一步推导

            1. 设相邻接触力依次为 P₁₂、P₂₃、P₃₄。静止时，各物块的静摩擦力会在 0 到 μmg 之间按需要取值；题设未给出各处静摩擦力，不能保证接触力的比例为 3∶2∶1，A 错误。
            2. 一起向右匀加速时，每块受到的滑动摩擦力都为 μmg。分别对右侧 3 块、2 块、1 块列式：P₁₂ = 3m(a + μg)、P₂₃ = 2m(a + μg)、P₃₄ = m(a + μg)，比例为 3∶2∶1，B 正确。
            3. t = μmg/k 时，F = μmg，小于整体最大静摩擦力 4μmg，系统尚未整体滑动。传感器示数取决于静摩擦分配，不能确定为 μmg，C 错误。若物块 1 的静摩擦力单独平衡 F，传感器示数可为零。
            4. t = 6μmg/k 时，F = 6μmg > 4μmg，系统已滑动。对整体：F − 4μmg = 4ma，得 a = (6μmg − 4μmg)/(4m) = 0.5μg，D 正确。
            运动时：a = F/(4m) − μg
P₁₂ : P₂₃ : P₃₄ = 3 : 2 : 1
F = 6μmg → a = 0.5μg
            易错提醒

            静摩擦力不一定达到 μmg，不能把运动状态下的接触力比例直接套到静止状态。
